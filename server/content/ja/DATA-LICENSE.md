# Japanese data licences

`vocab-data.json` is generated by `npm run ja:vocab-data` from:

- **KANJIDIC2** by the Electronic Dictionary Research and Development Group (EDRDG),
  used under the [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/) licence,
  see the [EDRDG licence statement](https://www.edrdg.org/edrdg/licence.html). Kanji readings, English meanings,
  stroke counts, frequency ranks and Sino-Vietnamese readings come from this file. **This derived data file is
  therefore also licensed under CC BY-SA 4.0.** The EDRDG asks that data be kept up to date: re-run the script
  monthly (see DEPLOY.md).
- **kanji-data** by David Gouveia (MIT licence), https://github.com/davidluzgouveia/kanji-data, for JLPT N5–N1
  kanji levels based on Jonathan Waller's JLPT resources (tanos.co.uk).
- **open-anki-jlpt-decks** (MIT licence), https://github.com/jamsinclair/open-anki-jlpt-decks, for the JLPT
  vocabulary lists, readings and English meanings (originally based on decks from tanos.co.uk).

Vietnamese meanings, the chosen Sino-Vietnamese reading and example sentences are added later by AI and stored in
the database; they are not part of this file.
