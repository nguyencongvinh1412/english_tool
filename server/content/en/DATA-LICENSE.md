# English vocabulary data

`vocab-data.json` is built by `npm run en:vocab-data` (server/scripts/buildEnVocab.ts) from:

| Source | Used for | Licence |
|---|---|---|
| New General Service List 1.2, TOEIC Service List 1.2, New Academic Word List 1.2 — Browne, C., Culligan, B. & Phillips, J. (newgeneralservicelist.com) | Word lists, frequency order, English definitions | CC BY-SA 4.0 |
| CEFR-J Wordlist Version 1.5, compiled by Yukio Tono, Tokyo University of Foreign Studies (via github.com/openlanguageprofiles/olp-en-cefrj) | CEFR levels A1–B2, parts of speech | Free for research and commercial use with this citation |
| Octanove Vocabulary Profile C1/C2 1.0, Octanove Labs | CEFR levels C1–C2 | CC BY-SA 4.0 |
| CMU Pronouncing Dictionary, Copyright (C) 1993-2015 Carnegie Mellon University. All rights reserved. | Pronunciations (converted to IPA) | BSD-style; redistribution keeps this notice |
| Tatoeba (tatoeba.org) | Example sentences and their Vietnamese translations | CC BY 2.0 FR |

The derived file is shared under CC BY-SA 4.0. Vietnamese meanings and collocations are added later
by the AI (admin action) and stored in the database, not in this file.

Credits are shown on the vocabulary page.
